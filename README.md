# Repository_YP01_YP04

# ИИ-помощник по выбору подарков
Программа помогает подбирать идеи подарков с учётом интересов получателя, возраста, бюджета, повода и ограничений.

## Возможности
- Отправка запросов в GigaChat
- Подбор вариантов подарков по пожеланиям пользователя
- Уточняющие вопросы, если для подбора не хватает информации
- Ответ в трёх разделах: подходящие подарки, описание и преимущества, рекомендация
- Отказ от ответов на темы, не связанные с выбором подарков
- Сохранение контекста диалога
- Команды история, очистить и выход
- Сохранение переписки в chat_history.txt

## Используемые технологии
- Python
- GigaChat-2 - языковая модель, к которой программа обращается через внешний API
- gigachat - библиотека для подключения к GigaChat
- python-dotenv - загрузка настроек из файла .env

## Требования
- Python 3.10 или новее
- Подключение к интернету
- Действующие данные для доступа к GigaChat
- Сертификат certs/russian_trusted_root_ca_pem.crt

## Установка
Все команды ниже выполняются из папки УП01/AI_agent

### Windows (PowerShell)
Перейти в папку окружения:
cd .\УП01\AI_agent

Создайте виртуальное окружение:
py -m venv .venv  

Установите зависимости:
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

### Linux
Перейти в папку окружения:
cd УП01/AI_agent

Создайте виртуальное окружение:
python3 -m venv .venv

Установите зависимости:
./.venv/bin/python -m pip install -r requirements.txt


## Настройка подключения
В папке AI_agent находится файл .env.example с названиями необходимых переменных
Скопируйте его и назовите копию .env

Откройте .env и заполните GIGACHAT_CREDENTIALS и GIGACHAT_SCOPE своими данными авторизации. Не публикуйте .env и не отправляйте его другим людям

Сертификат должен находиться по пути:
certs/russian_trusted_root_ca_pem.crt

В коде используется относительный путь, поэтому запускайте программу из папки AI_agent

## Запуск

## Запуск в Docker
Создайте папку для загрузки репозитория, загрузите репозиторий:
git clone https://github.com/nastyapluzhnik05-boop/my-ai-agent.git
и перейдите в папку AI_agent с помощью команды:
cd my-ai-agent/УП01/AI_agent

### Настройка:
Перед запуском необходимо создать файл .env с данными для подключения к GigaChat
Введите: 
cp .env.example .env
nano .env
Введите свои данные в файл и сохраните
Не публикуйте его на GitHub

### Сборка образа:
sudo docker build -t my-ai-agent:1.0 .

### Запуск:
sudo docker run -it --name my-ai-run --env-file .env my-ai-agent:1.0

### Для повторного запуска:
sudo docker start -ai my-ai-run

## Запуск через Docker Compose
Для запуска агента через Docker Compose:

1. Перейти в папку проекта
2. Убедиться, что файл .env заполнен
3. Собрать образ:
sudo docker compose build

4. Запустить агента:
sudo docker compose run --rm agent (одноразовый запуск, удаляется при завершении сеанса)
либо sudo docker compose run --name [придумайте название вашего докер-образа] agent

Чтобы запустить заново образ:
sudo docker start -ai [название вашего докер-образа]

5. Для завершения работы:
sudo docker compose down

Для работы необходимы Docker, Docker Compose и файл .env с настройками GigaChat

## Примеры запросов
- Помоги выбрать подарок для подруги, она любит мультфильм "Смешарики"
- Нужен подарок для мамы, она любит цветы
- Хочу подобрать подарок коллеге в пределах определённого бюджета

Команды:
- история - показывает количество сообщений и роли сообщений в текущем контексте
- очистить - очищает контекст диалога и начинает его заново
- выход - завершает программу

## Ограничения
- Для работы с моделью необходимы интернет и доступ к API GigaChat
- Без корректных значений GIGACHAT_CREDENTIALS и GIGACHAT_SCOPE подключение не будет настроено
- Помощник формирует рекомендации, а не проверяет наличие товаров и их актуальные цены. Эту информацию нужно уточнять отдельно
- История переписки дописывается в chat_history.txt. Не желательно оставлять там личные данные
- все команды с помощником выполняются после команды cd .\УП01\AI_agent, чтобы история чата корректно сохранялась в нужной папке проекта и программа не выдавала ошибок
## Структура проекта
- main.py - основной файл: принимает сообщения, обрабатывает команды, отправляет запросы в GigaChat и сохраняет переписку
- .env.example - пример файла с названиями переменных для подключения без настоящих учётных данных
- prompts.py - системная инструкция помощника
- requirements.txt - список внешних библиотек и их версий
- .gitignore - правила исключения локальных и служебных файлов из Git
- chat_history.txt - файл сохранения переписки
- certs - папка с сертификатом для подключения
- history_demo.py - отдельный файл для демонстрации работы с историей
- experiment_day13.txt - материал эксперимента за 13-й день
- last_prompt.txt и last_answer.txt - сохранённые примеры последнего запроса и ответа
- main_before_day13.py и main_before_day14.py - предыдущие версии основного файла
- .vscode - настройки проекта для VS Code
- .dockerignore - правила исключения локальных и служебных файлов из Docker
- Dockerfile - файл для запуска окружения Docker
## Безопасность
Не добавляйте в GitHub файл .env, ключи API, пароли, виртуальное окружение .venv и личные данные. В репозитории должен оставаться только пример настроек с пустыми значениями, если он нужен для демонстрации. Перед публикацией проверяйте не только .gitignore, но и уже добавленные в репозиторий файлы и историю коммитов.
