# Инвентаризация ИИ-агента

## 1. Паспорт проекта
Название: Помощник в выборе подарка
Назначение: помощь пользователю в подборе подарков с учётом интересов получателя, бюджета, повода и других пожеланий.
Основные функции:
- Приём сообщений пользователя.
- Подбор идей подарков с помощью ИИ.
- Поддержание контекста диалога.
- Просмотр количества сообщений в текущем контексте.
- Очистка контекста диалога.
- Завершение программы по команде «выход».
- Сохранение переписки в текстовый файл.
Файл запуска: main.py
Язык и версия Python: Python 3.14.7
Дата проверки: 20.11.2026

## 2. ИИ-компоненты
Модель и поставщик: GigaChat-2, Сбер.
API или локальная модель: внешний API GigaChat.
Библиотека подключения: gigachat версии 0.2.3.
Файл вызова модели: main.py.
Промпты и инструменты:
- Системная инструкция находится в prompts.py.
- Для контекста используются системное сообщение, сообщения пользователя и ответы ассистента.
- Доступны команды «история», «очистить» и «выход».

В инвентаризации учтено 7 основных компонентов:

1. Компонент: Python

## 4. Реестр файлов
- main.py — основной код программы, обработка запросов и команд; связан с GigaChat и prompts.py.
- prompts.py — системная инструкция помощника; используется в main.py.
- requirements.txt — список прямых внешних библиотек и их версий.
- chat_history.txt — файл сохранения переписки; используется в main.py.
- .env — локальный файл настроек подключения; должен быть создан пользователем и не публикуется в репозитории.
- .env.example — пример названий переменных без настоящих учётных данных.
- certs/russian_trusted_root_ca_pem.crt — сертификат для подключения к GigaChat API.
- .gitignore — правила исключения локальных и служебных файлов из Git.

## 5. Внешние сервисы и настройки
Основной внешний сервис — GigaChat API.

Для подключения используются переменные:
- GIGACHAT_CREDENTIALS — данные авторизации.
- GIGACHAT_SCOPE — область доступа.

Настройки загружаются из локального файла .env с помощью python-dotenv. Для защищённого соединения используется SSL-сертификат из папки certs.

## 6. Неустановленные сведения
- Точная версия SSL-сертификата в проекте не указана.
- Доступность GigaChat API зависит от интернета и действующих данных авторизации; в рамках инвентаризации отдельно не проверялась.
