## 5. Риски
Отсутствие доступа к GigaChat API → программа не сможет получать ответы → проверить интернет-соединение и настройки подключения

Попадание ключей доступа в открытый репозиторий → посторонние смогут воспользоваться учётными данными → не загружать .env и секретные данные на GitHub

Потеря файла истории → сохранённые сообщения будут утрачены → периодически создавать резервные копии

Изменение работы API или библиотек → программа может перестать работать → проверять совместимость и обновлять библиотеки при необходимости
