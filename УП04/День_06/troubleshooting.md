# Ошибки и их исправление
Во время выполнения работы возникло несколько проблем

1. Ошибка системного времени.
При выполнении sudo apt update появлялось сообщение Release file is not valid yet
Причина: автоматическая синхронизация времени Ubuntu была отключена
Исправление: включена синхронизация времени с помощью timedatectl

2. Ошибка подключения к репозиторию Docker
При установке Docker появлялось сообщение Connection refused
Причина: не удавалось подключиться к download.docker.com
После восстановления подключения установка продолжилась

3. Docker не мог подключиться к службе
Появлялись сообщения:
Unit docker.service could not be found
Cannot connect to the Docker daemon
Причина: Docker CLI был установлен, но Docker Engine ещё отсутствовал
Исправление: после восстановления доступа к репозиторию был установлен docker-ce

4. Проверка Docker
После установки Docker удалось запустить hello-world и nginx. Контейнеры работали, HTTP-запросы возвращали ответ
Основные проблемы удалось исправить
