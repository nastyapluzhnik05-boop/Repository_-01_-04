# День 9. Docker Compose
### Версии
- Docker: 29.1.0
- Docker Compose: 5.8.0
- Python в контейнере: 3.12.3

### Файл compose.yaml
- services - список сервисов.
- agent - название сервиса.
- build: . - сборка образа по Dockerfile.
- image - название и версия образа.
- env_file - подключение переменных из .env.
- stdin_open и tty - возможность вводить команды в терминале.

### Сборка и запуск
Сборка:
sudo docker compose build


Проверка конфигурации:
sudo docker compose config --quiet

Запуск:
sudo docker compose run --rm agent


Повторный запуск:
sudo docker compose run --rm agent


### Результаты
- Первый запрос - агент ответил
- Второй запрос - агент ответил
- Повторный запуск - успешно

### Образ и контейнер
Образ - подготовленный шаблон приложения со всеми необходимыми зависимостями
Контейнер - запущенный экземпляр образа, в котором работает приложение
